## Cloning into Fishen
> [!CAUTION]
> Keep the terminal open throughout the entire process!

<br>

* First, open up a terminal window and go into a directory, in which you will be cloning the repository into. Example with downloads:
```cmd
cd /path/to/downloads
```
* Clone the repository using the following command:
```cmd
git clone https://github.com/welltodozack-sketch/Fishen
```
* Next, open the newly generated directory.
```cmd
cd Fishen
```


## Setting up Raylib
> [!IMPORTANT]
> The repository provides the CMakeLists.txt file by default. Do not copy the following config example, unless your CMakeLists.txt file is lost.

Contents of CMakeLists.txt config file:
```cmake
cmake_minimum_required(VERSION 3.16)

project(FihGaem)
add_executable(Fishen src/Engine.cpp)
add_subdirectory(dependencies/raylib)

target_link_libraries(Fishen PRIVATE 
    raylib
)
```

* All you have to do is create a new dependencies folder inside the cloned repository:
```cmd
mkdir dependencies
```
* Then open the newly created folder:
```cmd
cd dependencies
```
* And clone Raylib:
```cmd
git clone https://github.com/raysan5/raylib
```
Your file structure should look something like this:

* Fishen -- Cloned folder
  * src
     * Engine.cpp
     * Fishen.hpp
  * dependencies
     * raylib
  * resources
     * textures
     * audio
  * CMakeLists.txt

## Generating build files
This is the last step we need to take, before we can have fun wrecking my tuna sandwich.
<br>

Lets create a new folder inside our Fishen cloned directory:

* *Assuming you are still inside dependencies:*
```cmd
cd .. ; mkdir build ; cd build
```
* *If you are located inside the Fishen cloned folder:*
```cmd
mkdir build ; cd build
```
* Last thing we need to run is the build command:
```cmake
cmake ..
```

If all is done correctly, it should start building the files (The build output is too long to past, it should return 0 if successful). When it finishes building, run this command to generate an executable of the program:

```cmake
cmake --build .
```
